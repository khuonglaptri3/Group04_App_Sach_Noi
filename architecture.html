1. Tổng Quan Project

Project là ứng dụng Android hỗ trợ đọc sách điện tử và nghe sách nói. Người dùng có thể đăng ký, đăng nhập, xem sách theo danh mục, đọc ebook, nghe audiobook, lưu tiến trình, bookmark, highlight, ghi chú, viết review, tải file về máy và quản lý thư viện cá nhân.

Chức năng chính

  • Đăng ký, đăng nhập, refresh token bằng Supabase Auth.
  • Trang chủ, khám phá, tìm kiếm, danh mục, sách liên quan.
  • Chi tiết sách tách theo loại: audiobook và ebook.
  • Nghe audio bằng MediaPlayer và Foreground Service.
  • Đọc EPUB, phân trang, bookmark, highlight, ghi chú.
  • Download audio/ebook bằng Android DownloadManager.
  • Quick Settings Tile để tiếp tục nghe nhanh.
  • Dọn cache bằng CleanupService.

Công nghệ chính

  • Java, AndroidX, AppCompat, Material Components.
  • OkHttp, Supabase REST/Auth/Storage/RPC.
  • Glide, Palette cho hình ảnh và màu giao diện.
  • Room, DAO, Repository, LiveData, ViewModel.
  • MediaPlayer, MediaSessionCompat, Notification, AudioManager.
  • WorkManager, Service, TileService, FileProvider, BroadcastReceiver động.

4.3 Content Provider

Project không tự viết ContentProvider riêng, mà dùng androidx.core.content.FileProvider. Provider được khai báo trong AndroidManifest.xml và cấu hình bằng res/xml/file_paths.xml. 

<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>

Class sử dụng trực tiếp: DownloadAdapter gọi FileProvider.getUriForFile(...) để mở file đã tải bằng URI an toàn dạng content://.

4.4 BroadcastReceiver

Project không khai báo BroadcastReceiver tĩnh trong Manifest. BroadcastReceiver được tạo động trong AudioPlayerService.

ReceiverNằm ở đâuLắng nghe actionXử lý

Hai receiver này được đăng ký bằng registerReceiver(...) trong Service và hủy bằng unregisterReceiver(...) trong onDestroy().

7. Lưu Trữ Dữ Liệu

Supabase

  • Auth: đăng ký, đăng nhập, refresh token.
  • REST: books, book_files, book_chapters, profiles, reviews, user_library, progress, bookmarks, highlights, notes.
  • Storage: avatar bucket.
  • RPC: search_books, add_book_review, toggle_favorite_book, notification, delete_user_account.

SharedPreferences

  • Class: SessionManager.
  • Preferences name: UserSession.
  • Lưu userId, userName, accessToken, refreshToken, lastPlayedBookId.

Room Database

  • Database: app_database.
  • Entity: BookEntity, table books.
  • DAO: BookDao.
  • Dùng để cache featured books và trả dữ liệu nhanh khi mạng chậm.

File local

  • Tải file bằng DownloadManager.
  • File audio: {bookId}_audio.mp3.
  • File ebook: {bookId}_ebook.epub.
  • Lưu trong app-specific external storage, thư mục Download.

9. Workflow Chính

Khởi động app

Android tạo MyApplication
    -> MyApplication.onCreate()
    -> setupBackgroundSync()
    -> WorkManager enqueueUniquePeriodicWork("BookSyncWork")
    -> LoginActivity là launcher

Đăng nhập

LoginActivity
    -> OkHttp POST /auth/v1/token?grant_type=password
    -> nhận access_token + refresh_token + user id
    -> SessionManager lưu SharedPreferences
    -> mở MainActivity

Trang chủ có cache

HomeTabFragment
    -> HomeViewModel
    -> BookRepository
    -> trả LiveData từ Room trước
    -> gọi Supabase lấy dữ liệu mới
    -> ghi Room bằng ExecutorService
    -> UI observe LiveData và cập nhật

Chi tiết sách mới

User chọn sách
    -> mở AudiobookDetailActivity hoặc EbookDetailActivity
    -> cả hai kế thừa BaseBookDetailActivity
    -> BaseBookDetailActivity fetch books + authors + categories + user_library + book_files
    -> subclass render mục lục riêng:
        AudiobookDetailActivity -> layout_toc_audiobook -> chapter audio
        EbookDetailActivity -> layout_toc_ebook -> chapter ebook

Phát audiobook

AudiobookDetailActivity
    -> PlayerManager.playBook()
    -> lưu lastPlayedBookId vào SessionManager
    -> MediaPlayer.setDataSource()
    -> MediaPlayer.prepareAsync()
    -> fetch last progress từ Supabase
    -> seekTo(position)
    -> mediaPlayer.start()
    -> ContextCompat.startForegroundService(AudioPlayerService)
    -> AudioPlayerService.startForeground()
    -> Notification + MediaSession + BroadcastReceiver động

Quick Settings Tile

User bấm tile "Tiếp tục nghe"
    -> QuickPlayTileService.onClick()
    -> nếu PlayerManager có currentBook: togglePlayPause()
    -> nếu không: SessionManager.getLastPlayedBookId()
    -> mở MainActivity với ACTION_RESUME_LAST_BOOK
    -> MainActivity mở lại detail của sách cuối

Đọc ebook

EbookDetailActivity
    -> readChapter()
    -> EbookReaderActivity
    -> lấy file EPUB từ Supabase book_files
    -> EpubExtractor tải/giải nén bằng thread nền
    -> paginationThread chia trang
    -> EbookPagerAdapter hiển thị
    -> lưu progress/bookmark/highlight/note lên Supabase

Download và mở file

BaseBookDetailActivity.handleDownloadClick()
    -> DownloadHelper.downloadFile()
    -> Android DownloadManager tải file vào external files Download
    -> DownloadManagerActivity hiển thị file đã tải
    -> DownloadAdapter dùng FileProvider.getUriForFile()
    -> mở file bằng content:// URI an toàn

12. Kết Luận Báo Cáo

Project được tổ chức theo MVC: Model chứa dữ liệu, View gồm Activity/Fragment/XML/Adapter, Controller/Helper xử lý logic. Ngoài MVC, project bổ sung Repository, ViewModel, LiveData, Room và WorkManager để hỗ trợ cache, quan sát dữ liệu và xử lý nền. Phát audiobook là phần nổi bật: PlayerManager quản lý MediaPlayer, AudioPlayerService chạy foreground để giữ audio khi thoát màn hình, còn QuickPlayTileService giúp tiếp tục nghe từ Quick Settings.

Một số Activity/Fragment vẫn gọi Supabase trực tiếp; nếu muốn kiến trúc sạch hơn có thể chuyển dần sang MVVM đầy đủ: UI → ViewModel → Repository → Local/Remote.
